# Texture Audit Tool 사용 안내

제작자: DotheZac · Unreal Engine 5.7 · Windows 64-bit · Editor 전용

Texture2D를 폴더·경로 기준으로 검사하고, 권장 변경이나 수동 설정을 적용하는 도구입니다. 최초 변경 직전의 속성을 저장해 나중에 복원할 수 있습니다.

## 설치와 실행

1. [Releases](https://github.com/DotheZac/TextureAuditTool/releases)에서 엔진 버전과 플랫폼이 일치하는 배포 ZIP을 받습니다. 배포 파일이 없다면 아직 다운로드가 시작되지 않은 상태입니다.
2. Unreal Editor를 종료하고 압축을 풉니다.
3. `TextureAuditTool` 폴더를 프로젝트의 `Plugins` 폴더 아래에 넣습니다. 최종 경로는 `<프로젝트>/Plugins/TextureAuditTool/TextureAuditTool.uplugin`입니다.
4. 프로젝트를 열고 플러그인 관리 화면에서 `Texture Audit Tool`이 활성화되어 있는지 확인합니다. 재시작을 요청하면 재시작합니다.
5. 에디터의 `Tools` 메뉴에서 `텍스처 검사 도구 / Texture Audit Tool`을 엽니다.

GitHub의 `Code → Download ZIP`은 문서 저장소를 내려받는 기능이며 설치 파일이 아닙니다. 배포 바이너리는 해당 엔진 버전과 플랫폼을 대상으로 합니다. 모듈 누락·버전 불일치 오류가 나오면 사용한 ZIP 이름과 정확한 UE 버전을 피드백에 적어주세요.

## 언어

에디터 언어가 한국어이면 한국어, 그 외에는 영어로 표시됩니다. 언어를 변경한 뒤에는 에디터를 재시작하세요. 플러그인 관리 화면의 이름과 설명은 영어입니다.

## 검사와 결과 확인

- `폴더 선택`: Content 폴더를 선택하고 검사합니다.
- `경로 검사`: `/Game/Textures` 같은 패키지 경로나 프로젝트 Content 폴더 경로를 입력하고 검사합니다.
- 검색과 검토 순위 필터로 결과를 좁힐 수 있습니다.
- 결과를 선택하면 문제 원인, 적용할 변경, 예상 효과와 적용 후 확인사항을 볼 수 있습니다.
- 여러 행은 `Ctrl` 또는 `Shift`로 선택합니다. 하단 상세 설명은 마지막으로 선택한 항목을 기준으로 합니다.

### 검토 순위

| 표시 | 의미 |
| --- | --- |
| 1순위 | 가장 먼저 검토할 항목 |
| 2순위 | 다음으로 검토할 항목 |
| 3순위 | 최적화 또는 용도를 검토할 항목 |
| 해당 없음 | 현재 검사 규칙에서 검토 사항이 발견되지 않은 항목 |

순위는 위험 여부나 수정 개수가 아닙니다. `해당 없음`도 모든 환경에서 최적이라는 뜻은 아닙니다. 검토 순위와 자동 적용할 권장 변경의 유무는 별개입니다.

### 포맷과 메모리

`원본 크기`와 `예상 출력`은 구분됩니다. 권장 변경은 원본 이미지 파일을 수정하지 않습니다.

`Editor 포맷`과 `Editor 허용 Mip`은 현재 Editor 플랫폼의 빌드 데이터에 근거한 값입니다. 허용 Mip 용량은 현재 화면에 상주하는 용량이 아니라, Device Profile과 결합 LOD Bias가 허용하는 Fully Loaded GPU 메모리입니다. 설정 기반 예상값이나 다른 플랫폼·패키징 결과의 메모리와는 구분해서 읽어야 합니다.

Virtual Texture는 공유 물리 풀을 사용하므로 개별 에셋의 GPU 용량을 표시하지 않습니다.

## 권장 변경과 수동 설정

1. 결과를 선택하고 변경 내용과 적용 후 확인사항을 읽습니다.
2. `선택 권장사항 적용`을 누르거나 우클릭의 `수동 설정`에서 속성을 지정합니다.
3. 확인창을 읽고 적용한 뒤 실제 사용 화면과 Texture Editor에서 결과를 확인합니다.
4. 결과가 적절하면 에디터에서 에셋을 저장합니다. 취소하려면 `Ctrl+Z`를 사용합니다.

다중 선택한 텍스처에 같은 수동 설정을 한 번에 적용할 수 있습니다. 수동 설정 항목은 최대 텍스처 크기, 압축 방식, Texture Group, Mip 생성, 일반·Virtual Texture 스트리밍, sRGB와 알파 제외 압축입니다.

변경은 UE 텍스처 속성에 적용되며 원본 이미지는 유지됩니다. 에셋은 자동 저장되지 않습니다. 실제 용도와 화질에 따라 권장값을 적용하지 않는 편이 적절할 수 있습니다.

## 원래 속성으로 복원

1. 검사 결과에서 복원할 텍스처를 하나 이상 선택합니다.
2. 우클릭의 `텍스처 속성 초기화`를 선택합니다.
3. 확인창을 읽고 진행하면 도구로 처음 변경하기 직전의 속성으로 복원됩니다.
4. 결과를 확인하고 에셋을 저장합니다. 복원 작업도 `Ctrl+Z`로 되돌릴 수 있습니다.

**엔진 기본값으로 초기화하는 기능이 아닙니다.** 도구에서 관리하는 해상도 제한, LOD Bias, 압축, Texture Group, Mip, 스트리밍, 색상·알파와 빌드 리사이즈 속성을 저장된 값으로 복원합니다. 원본 이미지와 임포트 데이터는 유지됩니다.

- 실행하거나 검사만 할 때는 원래 설정을 저장하지 않습니다. 권장 변경·수동 설정으로 실제 변경할 때 변경 직전 값을 저장합니다.
- 같은 원본에서는 여러 번 변경해도 최초 저장값을 유지합니다. 복원 후에도 이 기록은 남습니다.
- 저장된 원래 값이 없거나 재임포트로 원본 식별자가 바뀐 항목은 건너뜁니다. 기록이 생기기 전 변경을 소급 복원하지는 못합니다.
- 저장 대상 속성을 나중에 직접 수정했더라도 복원하면 최초 저장값으로 돌아갑니다.
- 속성을 원래대로 복원해도 에디터의 미저장 표시는 남을 수 있습니다. 복원 결과를 유지하려면 에셋을 저장하세요.

## 수정됨과 검토 상태

수정할 필요는 없지만 검토는 마친 텍스처도 있습니다. 이런 경우 `수정됨`은 체크되지 않고, `검토 상태`만 `검토 완료`로 표시됩니다.

- `수정됨`은 도구의 변경 기록에 따른 읽기 전용 표시이며, 에디터의 미저장 표시와는 별개입니다.
- 우클릭에서 `미검토 / 검토 필요 / 검토 완료`를 지정할 수 있습니다. 검토 상태만 바꿔도 텍스처 속성은 변경되지 않습니다.
- 권장 변경·수동 설정 적용 직후에는 `검토 완료`로 표시됩니다. 이는 화질 자동 검증을 뜻하지 않으므로 실제 사용 화면을 확인하세요.
- 기록된 설정과 현재 속성이 달라지면 `검토 필요`로 표시될 수 있습니다.
- `텍스처 속성 초기화`는 원래 속성과 함께 저장 당시의 수정됨·검토 상태도 복원합니다.
- `수정 이력 및 검토 상태 초기화`는 표시 기록만 지웁니다. 텍스처 속성과 복원용 원래 설정은 유지됩니다.

## 프로젝트에 저장되는 기록

| 파일 | 내용 |
| --- | --- |
| `Config/TextureAuditTool.ini` | 수정됨·검토 상태와 Undo/Redo 표시를 위한 기록 |
| `Config/TextureAuditToolOriginalSettings.ini` | 복원에 사용하는 최초 변경 전 값 |

두 파일은 사용하는 프로젝트의 `Config`에 저장됩니다. 팀에서 파일을 공유하면 같은 기록을 사용할 수 있습니다. 플러그인 업데이트 시 유지하고, 다른 프로젝트에 플러그인을 배포할 때는 현재 프로젝트의 기록을 함께 넣지 마세요.

## 에셋 열기와 새로고침

| 동작 | 사용법 |
| --- | --- |
| 텍스처 열기 | 결과 더블 클릭 또는 결과 목록에서 선택 후 `Enter` |
| 참조 확인 | 우클릭 → `Reference Viewer` |
| 에셋 위치 확인 | 우클릭 → `Content Browser에서 찾기` |
| 현재 결과 다시 검사 | 도구 창에서 `F5` |
| 변경 취소·재실행 | 에디터의 Undo/Redo 사용. 이후 결과가 갱신됩니다. |

## CSV 내보내기

현재 검색과 필터에 표시된 행을 CSV로 저장합니다. 선택한 행만 내보내는 기능은 아닙니다. 열 이름은 영어이며, 검사 설명과 검토 순위 값은 에디터 언어를 따릅니다. CSV에는 에셋 이름과 패키지 경로가 포함되므로 외부에 공유하기 전에 내용을 확인하세요.
