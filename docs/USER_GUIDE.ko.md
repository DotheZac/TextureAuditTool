# Texture Audit Tool 사용 안내

제작자: DotheZac · 대상: Unreal Engine 5.7, Windows 64-bit · Editor 전용

## 설치

1. [Releases](https://github.com/DotheZac/TextureAuditTool/releases)에서 UE 버전과 플랫폼이 일치하는 배포 ZIP을 받습니다. 배포 파일이 없다면 아직 다운로드가 시작되지 않은 상태입니다.
2. Unreal Editor를 종료하고 압축을 풉니다.
3. `TextureAuditTool` 폴더를 프로젝트의 `Plugins` 폴더 아래에 넣습니다. 최종 경로는 `<프로젝트>/Plugins/TextureAuditTool/TextureAuditTool.uplugin`입니다.
4. 프로젝트를 열고 플러그인 관리 화면에서 `Texture Audit Tool`이 활성화되어 있는지 확인합니다. 재시작을 요청하면 재시작합니다.
5. 에디터의 `Tools` 메뉴에서 `텍스처 검사 도구 / Texture Audit Tool`을 엽니다.

배포 ZIP은 컴파일된 플러그인용입니다. GitHub의 `Code → Download ZIP`은 문서 저장소를 내려받는 기능이며 설치 파일이 아닙니다. 다른 엔진 버전이나 별도 소스 빌드 엔진에 동일한 바이너리를 사용할 수 있다고 보장하지 않습니다. 모듈 누락이나 버전 불일치가 나오면 사용한 ZIP 이름과 UE의 정확한 버전을 함께 신고하세요.

## 언어

에디터 언어가 한국어이면 한국어, 그 외에는 영어로 표시됩니다. 언어를 변경한 뒤 에디터를 재시작하면 기존 창과 검사 결과에도 같은 언어를 적용할 수 있습니다. 플러그인 관리 화면의 이름과 설명은 영어입니다.

## 검사

- `폴더 선택`: Content 폴더를 선택하고 검사합니다.
- `경로 검사`: `/Game/Textures` 같은 패키지 경로나 프로젝트 Content 폴더 경로를 입력하고 검사합니다.
- `선택 에셋 검사`: Content Browser에서 선택한 Texture2D를 검사합니다.
- 검색과 순위별 체크박스로 결과를 좁힐 수 있습니다.

## 검토 순위

| 표시 | 의미 |
| --- | --- |
| 1순위 | 가장 먼저 검토하도록 분류된 항목 |
| 2순위 | 다음으로 검토하도록 분류된 항목 |
| 3순위 | 최적화 또는 용도를 검토할 항목 |
| 해당 없음 | 현재 검사 규칙에서 검토 사항이 발견되지 않은 항목 |

순위는 위험 여부나 수정 개수가 아닙니다. `해당 없음`도 모든 환경에서 최적이라는 뜻은 아닙니다. 자동 권장 변경 유무와 검토 순위는 별개입니다.

## 결과와 메모리 읽기

`원본 크기`와 `예상 출력`은 구분해서 표시됩니다. 권장 변경은 원본 이미지 파일을 수정하지 않습니다. `Editor 포맷`과 `Editor 허용 Mip`은 현재 Editor 플랫폼의 빌드 데이터에 근거한 값이며, 설정 기반 예상값과 구분됩니다. 허용 Mip 용량은 현재 화면에서 실제로 상주하는 Mip 용량이 아니라 Device Profile과 결합 LOD Bias가 허용하는 Fully Loaded GPU 메모리입니다.

Virtual Texture는 공유 물리 풀을 사용하므로 개별 에셋의 GPU 용량을 표시하지 않습니다. 다른 플랫폼이나 패키징 결과의 메모리를 그대로 의미하지는 않습니다.

## 변경 적용

1. 결과를 선택하고 하단의 문제 원인, 적용할 변경, 예상 효과, 적용 후 확인사항을 읽습니다.
2. 여러 행은 `Ctrl` 또는 `Shift`로 선택합니다. 하단 설명은 마지막으로 선택한 항목을 기준으로 합니다.
3. `선택 권장사항 적용`을 누르거나 우클릭의 `수동 설정`에서 속성을 지정합니다.
4. 확인창을 읽고 적용한 뒤 실제 사용 화면과 Texture Editor에서 결과를 확인합니다.
5. 에셋 변경은 자동 저장되지 않습니다. 결과가 적절하면 에디터에서 에셋을 저장합니다. 되돌리려면 `Ctrl+Z`를 사용합니다.

권장 변경과 수동 설정은 UE 텍스처 속성을 변경합니다. 화질과 머티리얼 용도에 따라 권장값을 적용하지 않는 편이 적절할 수 있습니다.

## 검토 기록과 바로가기

- `수정됨`은 도구로 적용한 변경 이력이며 직접 체크하지 않는 읽기 전용 표시입니다.
- 우클릭에서 검토 상태를 `미검토 / 검토 필요 / 검토 완료`로 바꿀 수 있습니다.
- 변경 적용 시 기본 검토 상태는 `검토 완료`입니다. 이 표시는 화질 검증의 자동 판정을 뜻하지 않습니다.
- 기록은 프로젝트의 `Config/TextureAuditTool.ini`에 저장됩니다. 팀에서 해당 파일을 공유하면 기록도 공유할 수 있습니다. 플러그인 업데이트 시 이 파일을 덮어쓰지 마세요.
- 우클릭의 기록 초기화는 텍스처 속성을 되돌리는 기능이 아닙니다.
- 더블 클릭: 텍스처 열기. 결과 목록에서 `Enter`: 선택한 텍스처 열기.
- 도구 창에서 `F5`: 현재 결과 새로고침. Undo/Redo 후에도 결과가 갱신됩니다.
- 우클릭: Reference Viewer, Content Browser에서 찾기, 수동 설정과 검토 기록 메뉴.

## CSV 내보내기

현재 검색과 필터에 표시된 행을 CSV로 저장합니다. 선택한 행만 내보내는 기능은 아닙니다. 열 이름은 영어이며, 검사 설명과 검토 순위 값은 에디터 언어를 따릅니다. CSV에는 에셋 이름과 패키지 경로가 포함되므로 외부에 공유하기 전에 내용을 확인하세요.
